⊕ Vad är en DDoS-attack?

En Distributed Denial of Service-attack innebär att ett botnät av tusentals datorer samtidigt skickar enorma mängder trafik till en server tills den kraschar.

⚠ Viktigt att förstå: Eftersom attacken kommer från tusentals källor samtidigt, letar säkerhetsexperter efter en "signatur". Ett gemensamt mönster i trafiken som skiljer botnätet från riktiga användare.
▷ Verkligt exempel · GitHub (2018)
GitHub utsattes för en enorm attack med 1,35 terabit trafik per sekund. Genom att använda avancerade skyddstjänster kunde de filtrera bort den skadliga trafiken baserat på dess mönster, och sajten var snart uppe igen.
⚙ Hur fungerar det?

Angriparen fjärrstyr tusentals infekterade enheter (botnät). På kommando börjar alla skicka förfrågningar. Servern försöker svara på allt, men blir så upptagen att riktiga användare inte längre kommer in.

1. Botnät aktiveras
2. Samma order skickas
3. Servern översvämmas
4. Tjänsten dör
◎ Hur stoppar vi attacken?
  • Mönsterigenkänning: Identifiera om alla anfallande datorer gör något specifikt, som att använda en gammal webbläsare eller fråga efter samma fil.
  • Rate limiting: Sätt en gräns för hur många gånger en besökare får "knacka på dörren" per sekund.
  • Trafikfiltrering: Använd brandväggar för att automatiskt sortera bort trafik som matchar attackens signatur.
  • CDN-skydd: Använd externa tjänster som fungerar som en "krockkudde" och absorberar trafiken innan den når vår server.
